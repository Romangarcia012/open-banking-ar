# 🏦 Open Banking Argentina

> Primera aplicación de Open Banking en Argentina, alineada con las iniciativas del BCRA.

## Estado del proyecto

🚧 En construcción

## Descripción

Este proyecto implementa una plataforma de Open Banking para Argentina, siguiendo los lineamientos del Banco Central de la República Argentina (BCRA) y los estándares internacionales de Open Banking.

## Stack Tecnológico

- **Backend:** Node.js + Express + TypeScript
- **Frontend:** React + Next.js + TypeScript
- **Base de datos:** PostgreSQL
- **Autenticación:** OAuth 2.0 / OpenID Connect
- **Infraestructura:** Docker + Docker Compose + GitHub Actions

## Estructura del proyecto

```
open-banking-ar/
├── backend/          # API REST
├── frontend/         # Aplicación web
├── docs/             # Documentación técnica y regulatoria
└── infra/            # Infraestructura
```
